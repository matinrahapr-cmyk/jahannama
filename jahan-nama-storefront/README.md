# رابط فروشگاه آجر جهان‌نما

رابط واقعی و ریسپانسیو با Next.js و TypeScript، بر پایه معماری اطلاعات فاز ۱، سیستم طراحی فاز ۲ و رنگ‌های استخراج‌شده از لوگوی برند.

## اجرا در ویندوز

1. پوشه را کامل Extract کنید.
2. پوشه‌ای را در VS Code باز کنید که `package.json` داخل آن است.
3. در Terminal اجرا کنید:

```powershell
npm.cmd install
npm.cmd run dev
```

4. مرورگر: `http://localhost:3000`

## فایل‌های مهم

- `lib/palette.json`: پالت رنگ ذخیره‌شده
- `lib/design-tokens.ts`: توکن‌های قابل استفاده در کد
- `app/globals.css`: استایل و متغیرهای CSS
- `app/page.tsx`: صفحه اصلی فروشگاه
- `components/`: کامپوننت‌های رابط

فرم‌ها در این نسخه نمایشی هستند و هنوز به بک‌اند و دیتابیس متصل نشده‌اند.
