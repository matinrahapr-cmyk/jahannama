# سایت آجر جهان‌نما — نسخه GitHub Pages

این بسته نسخه استاتیک سایت آجر جهان‌نما است و با هر بار Push روی شاخه `main`
به‌صورت خودکار در GitHub Pages منتشر می‌شود.

## انتشار

1. همه فایل‌های این پوشه را در ریشه Repository آپلود کنید.
2. در GitHub به `Settings → Pages` بروید.
3. گزینه `Source` را روی `GitHub Actions` قرار دهید.
4. اجرای workflow با نام `Deploy GitHub Pages` را در تب Actions دنبال کنید.

پس از پایان موفق اجرا، نشانی سایت در `Settings → Pages` نمایش داده می‌شود.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال را باز کنید.

## ساختار محصولات

- آجر انگلیسی و آجر شاموتی زیرمجموعه آجر نسوز هستند.
- آجر شومینه، آجر کرکره‌ای و آجر تایل زیرمجموعه آجر مشکی هستند.
- کلیک روی هر نام محصول یا کارت، صفحه اختصاصی همان محصول را باز می‌کند.
