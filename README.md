# آجر جهان‌نما — نسخه GitHub Pages

نسخه استاتیک و واکنش‌گرای وب‌سایت آجر جهان‌نما، آماده انتشار مستقیم روی GitHub Pages.

## انتشار

1. همه فایل‌های این پوشه را در شاخه `main` مخزن GitHub قرار دهید.
2. در GitHub به `Settings → Pages` بروید.
3. در بخش `Build and deployment`، گزینه `Source` را روی `GitHub Actions` بگذارید.
4. وارد تب `Actions` شوید و تا سبز شدن اجرای `Deploy to GitHub Pages` صبر کنید.

آدرس سایت پس از انتشار به شکل زیر خواهد بود:

```text
https://USERNAME.github.io/REPOSITORY/
```

## اجرای محلی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## نکته

این خروجی برای نمایش عمومی و معرفی محصولات است. فرم استعلام از طریق تماس و واتساپ کار می‌کند و به دیتابیس نیاز ندارد.
