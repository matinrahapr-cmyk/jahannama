# آجر جهان‌نما — نسخه GitHub Pages

این نسخه شامل تم اصلی جهان‌نما، منوی چندسطحی، فیلتر محصولات، ۳۴ کارت محصول و
صفحه اختصاصی هر محصول است.

## انتشار

1. تمام فایل‌ها را در ریشه Repository و شاخه `main` آپلود کنید.
2. از `Settings → Pages`، گزینه Source را روی `GitHub Actions` بگذارید.
3. اجرای workflow را در تب `Actions` بررسی کنید.

پس از اتمام Deploy، لینک سایت در بخش Pages نمایش داده می‌شود.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.
